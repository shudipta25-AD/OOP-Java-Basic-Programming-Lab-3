# Java Number System Programs

This repository contains basic Java programs for practicing number system conversions and arithmetic operations.

## Topics Covered
- Binary addition and multiplication
- Decimal to Binary, Octal and Hexadecimal
- Binary to Decimal, Octal and Hexadecimal
- Octal to Decimal, Binary and Hexadecimal
- Hexadecimal to Decimal, Binary and Octal
- Basic Java input and output

**Language:** Java  
**Purpose:** Java Programming Practice
